# lat_text_latin_library_macronized

Automatically macronized texts from (cltk/lat_text_latin_library)[https://github.com/cltk/lat_text_latin_library/].

The initial pass uses (Alatius/latin-macronizer)[https://github.com/Alatius/latin-macronizer] to enforce unambiguous macrons. Then an LLM is queried to resolve the ambiguous or unknown forms.
